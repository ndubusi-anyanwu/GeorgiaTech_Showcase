# Machine Learning Research — IEEE-Format Papers

**Subject Area:** Machine Learning · Supervised Learning · Reinforcement Learning · Optimization · Research Writing

---

## What It Does

This folder contains four original research papers written in IEEE double-column format, each examining a different machine learning paradigm. The papers include experimental design, empirical benchmarking across multiple algorithms and datasets, analysis of bias-variance trade-offs, and interpretation of results in the context of real-world applicability. Collectively, they represent a rigorous survey of core ML techniques from a researcher's perspective.

### Papers Included

| File | Topic |
|------|-------|
| `CS7641_A1_Supervised_Learning_IEEE.pdf` | Supervised Learning — benchmarking decision trees, neural networks, SVMs, boosting, and KNN across multiple classification problems |
| `CS7641_A2_Randomized_Optimization_IEEE.pdf` | Randomized Optimization — comparing genetic algorithms, simulated annealing, and MIMIC on combinatorial optimization problems |
| `CS7641_A3_Unsupervised_Learning_IEEE.pdf` | Unsupervised Learning and Dimensionality Reduction — K-Means, EM clustering, PCA, ICA, and manifold methods evaluated against labeled holdout data |
| `CS7641_A4_Reinforcement_Learning_IEEE.pdf` | Reinforcement Learning — Q-learning and policy iteration applied to Markov Decision Process environments with convergence analysis |

## Problem Addressed

ML practitioners need to understand not just how to run algorithms, but how to reason about algorithm selection, hyperparameter sensitivity, computational trade-offs, and generalization. Each paper addresses a core question: given a problem class, which algorithm family is appropriate, and why — backed by empirical evidence rather than intuition.

## Practical Relevance

These papers demonstrate the kind of structured, evidence-based ML reasoning required in applied research, AI product development, and security analytics roles where algorithmic decisions need to be defensible. The reinforcement learning and optimization work has direct parallels to sequential decision-making problems in autonomous systems and adversarial AI environments.
