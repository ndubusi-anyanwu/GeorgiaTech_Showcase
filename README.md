## Featured Projects

### 01 · [AI-Enhanced Phishing Research](./01_AI_Enhanced_Phishing_Research/)
*CS 8803: AI and Cybersecurity — MS Cybersecurity Flagship*

IEEE-format research paper investigating how large language models can be weaponized to generate context-aware phishing attacks at scale, with a proposed detection framework for resource-constrained SMB environments. Sits at the exact intersection of AI risk and cybersecurity — the fastest-growing threat surface in enterprise security today.

**Keywords:** LLMs · Social Engineering · AI Threat Modeling · Detection Framework · SMB Security

### 06 · [SHA-1 Length Extension Attack](./06_Applied_Cryptography_SHA1_Attack/)
*CS 6260: Applied Cryptography*

From-scratch Python implementation of the SHA-1 length extension attack — reconstructing internal hash state from an intercepted MAC digest to forge authenticated messages without the secret key. Directly applicable to auditing legacy API authentication schemes.

**Keywords:** SHA-1 · Merkle-Damgård · Cryptographic Attacks · MAC Forgery · Python
